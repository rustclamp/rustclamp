# Starter kits

These are runnable examples for trying RustClamp and adjacent frontend tools.
They are separate from `clamp init`. Its `--web` template uses Vite+ and Tailwind 4
with a Rust server; the other templates are Rust-only.

| Kit | Stack | Status | Try it |
| --- | --- | --- | --- |
| [Vue Todo](viteplus-vue-todo) | Vite+ 1, Vue 3, TypeScript | Ready to install | Local todo app with browser storage |

Start with Vue Todo to explore a small interactive app. A blog and a recreation
of the RustClamp landing page can be added as separate demos when useful.
